    Authorization: Bearer YOUR_KEY. Accepted commands return 202 and a job ID; poll status until busy is false, then check error. An active operation returns 409 for conflicting commands. Configuration uses config_revision to reject stale edits. Hardware fault injection and reset remain unavailable. Named positions and real sequences are supported.
